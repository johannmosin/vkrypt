ℹ️ How It Works

  1. Generate or import your encryption key
  2. Exchange keys with contacts through a secure channel (Signal, in-person, etc.)
  3. Add contact keys in the section above for group chats
  4. Enable encryption using the toggle button
  5. Messages are automatically encrypted/decrypted in VK chats
⚠️ Important Security Notes:
  • Never share your private key through VK or any unsecured channel
  • Verify key fingerprints with contacts through a secure channel
  • Backup your keys - loss means permanent message loss
  • This extension encrypts client-side; VK servers never see unencrypted messages
