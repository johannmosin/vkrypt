# VKrypt 🔐

**Сквозное шифрование для ВКонтакте | End-to-End Encryption for VKontakte**

VKrypt - это расширение для браузеров Firefox и Chrome, добавляющее сквозное шифрование (E2EE) в сообщения ВКонтакте.

## Возможности

✅ **Полноценное E2EE** - Шифрование AES-256-GCM с обменом ключами ECDH P-256  
✅ **Внешний обмен ключами** - Ключи передаются вне ВКонтакте (через мессенджеры, лично и т.д.)  
✅ **Работа с группами** - Поддержка групповых чатов  
✅ **Смешанные сообщения** - Автоматическое определение зашифрованных и обычных сообщений  
✅ **Минимальное вмешательство** - Не нарушает стандартный интерфейс VK  
✅ **Видимые маркеры** - 🔒 (активно), ⚠️ (нужны ключи), 🔓 (отключено)  
✅ **Тёмная тема** - Стиль соответствует дизайну ВКонтакте  
✅ **Мультиязычность** - Русский (по умолчанию) и английский с автоопределением  
✅ **Firefox Mobile** - Работает на мобильных устройствах Firefox  

## Установка

### Firefox Desktop
1. Откройте `about:debugging`
2. Нажмите "Загрузить временный модуль" (Load Temporary Add-on)
3. Выберите файл `manifest.json` из папки VKrypt

### Firefox Mobile
1. Установите Firefox Nightly
2. Включите поддержку расширений в `about:config`:
   - `xpinstall.signatures.required` → `false`
3. Перейдите на страницу с VK
4. Откройте меню → Настройки → Расширения
5. Добавьте VKrypt как временное расширение

### Chrome
1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика"
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку VKrypt

## Использование

### 1. Генерация ключей
1. Откройте расширение (клик по иконке замка)
2. Нажмите "Сгенерировать ключи"
3. Дождитесь завершения генерации

### 2. Обмен ключами
**Ваш открытый ключ:**
1. Скопируйте свой открытый ключ из расширения
2. Отправьте его контакту через защищённый канал (Signal, Telegram Secret Chat, лично)

**Ключ контакта:**
1. Получите открытый ключ контакта тем же способом
2. Вставьте ключ в расширение
3. Укажите имя контакта (или ID)
4. Нажмите "Сохранить"

### 3. Отправка зашифрованных сообщений
1. Откройте чат ВКонтакте
2. Включите шифрование кнопкой "Шифрование" в шапке чата
3. Напишите сообщение
4. Нажмите **Shift+Enter** для отправки зашифрованного сообщения
5. Обычный Enter отправит незашифрованное сообщение

### 4. Получение зашифрованных сообщений
Зашифрованные сообщения автоматически расшифровываются при отображении. Рядом с ними появляется значок 🔒.

## Структура URL чатов

VKrypt поддерживает все форматы URL ВКонтакте:
- `https://vk.com/im/convo/239940220` - личный чат
- `https://vk.com/im/convo/c123456` - групповой чат
- `https://vk.com/im/convo/239940220?entrypoint=list_all` - чат с параметрами
- `https://vk.com/im?sel=123` - старый формат

## Технические детали

### Криптография
- **Обмен ключами**: ECDH P-256 (NIST Curve)
- **Шифрование**: AES-256-GCM
- **Вектор инициализации**: 96-bit случайный IV для каждого сообщения
- **Производная функция**: PBKDF2 с SHA-256, 100,000 итераций

### Формат зашифрованного сообщения
```json
{
  "version": 1,
  "algorithm": "AES-GCM-256",
  "iv": "<base64>",
  "ciphertext": "<base64>",
  "isGroup": false,
  "timestamp": 1234567890
}
```

Сообщения помечаются префиксом `VKRYPT:` для автоматического обнаружения.

## Безопасность

⚠️ **Важные предупреждения:**

1. **Ключи хранятся локально** - в хранилище браузера. При очистке данных расширения ключи будут утеряны.

2. **Резервное копирование** - сохраните свой закрытый ключ в надёжном месте!

3. **Проверка ключей** - всегда проверяйте отпечатки ключей через независимый канал связи.

4. **Групповые чаты** - текущая реализация использует упрощённую схему для групп. Для максимальной безопасности обменивайтесь ключами со всеми участниками.

5. **Метаданные** - VKrypt шифрует только содержимое сообщений. Метаданные (кто, когда, кому) остаются видимыми ВКонтакте.
