# VKrypt - E2EE для ВКонтакте

## Описание
VKrypt — это расширение для браузеров Firefox и Chrome, которое добавляет сквозное шифрование (E2EE) к сообщениям ВКонтакте.

## Возможности
- ✅ Сквозное шифрование с использованием AES-256-GCM и ECDH P-256
- ✅ Обмен ключами происходит вне ВКонтакте
- ✅ Работает в Firefox Desktop и Firefox Mobile
- ✅ Работает в Chrome
- ✅ Интеграция с нативным интерфейсом сообщений VK
- ✅ Поддержка зашифрованных и незашифрованных сообщений
- ✅ Поддержка групповых чатов
- ✅ Минимальное вмешательство в интерфейс VK
- ✅ Видимые индикаторы статуса шифрования
- ✅ Русский и английский языки с автоопределением

## Установка

### Firefox Desktop
1. Откройте `about:debugging`
2. Нажмите "Загрузить временный модуль" (Load Temporary Add-on)
3. Выберите файл `manifest.json` из папки VKrypt

### Firefox Mobile
1. Установите Firefox Nightly
2. Включите поддержку расширений в `about:config`
3. Следуйте инструкциям по установке неподписанных расширений
4. Или упакуйте расширение для публикации в AMO

### Chrome
1. Откройте `chrome://extensions/`
2. Включите "Режим разработчика"
3. Нажмите "Загрузить распакованное расширение"
4. Выберите папку VKrypt

## Использование

### 1. Генерация ключей
1. Откройте расширение
2. Нажмите "Сгенерировать ключи"
3. Дождитесь завершения генерации

### 2. Экспорт вашего публичного ключа
1. В расширении нажмите "Копировать" рядом с вашим публичным ключом
2. Отправьте ключ контакту через защищённый канал (не через VK!)

### 3. Импорт публичного ключа контакта
1. Получите публичный ключ от контакта
2. Вставьте ключ в поле "Публичный ключ контакта"
3. Введите имя контакта
4. Нажмите "Сохранить"

### 4. Отправка зашифрованных сообщений
1. Откройте чат с контактом
2. Убедитесь, что статус показывает "🔒 Шифрование активно"
3. Напишите сообщение и отправьте его как обычно

## Локализация
Расширение поддерживает два языка:
- **Русский** (по умолчанию)
- **Английский**

Язык можно изменить в настройках расширения:
- **Авто** — автоматически определяется по языку VK
- **Русский** — всегда русский
- **English** — всегда английский

## Безопасность
- Ключи генерируются локально с использованием Web Crypto API
- Приватные ключи никогда не покидают устройство
- Для шифрования используется AES-256-GCM
- Для обмена ключами используется ECDH P-256
- Публичные ключи передаются только через внешние каналы

## Совместимость
- Firefox 57+
- Firefox для Android 57+
- Chrome 88+
- Другие браузеры на основе Chromium
